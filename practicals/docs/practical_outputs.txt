===== Note on output ordering =====
When stdout is a pipe or a file, glibc buffers it fully instead of line-by-line.
fork() duplicates that unflushed buffer, so lines printed before fork() can appear
twice. Running the programs directly on a terminal (line-buffered), or adding
fflush(stdout) before fork(), removes the duplication. This does not change the
PID/PPID values being demonstrated.

===== Practical 5a : prog5 (producer-consumer over an anonymous pipe) =====
$ ./prog5
Consumer: Received 10000 messages

Producer: Sent 10000 messages
Total data transferred : 1000000 bytes
Communication time     : 0.012969 seconds
Communication throughput: 73.53 MB/s

Three consecutive runs:
  run 1  0.012969 s   73.53 MB/s
  run 2  0.013929 s   68.47 MB/s
  run 3  0.012304 s   77.51 MB/s
All three received exactly 10000 messages - no loss, no interleaving, because
100 bytes is well under PIPE_BUF (4096) so each write is atomic.
